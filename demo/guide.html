Writing with Stets

Comments are written in Markdown: plain text with a few marks for formatting. The toolbar adds the marks for you, and Preview shows how the comment will look.

Text

  • Bold: **Bold**, or Cmd/Ctrl+B
  • Italic: _Italic_, or Cmd/Ctrl+I
  • Strikethrough: ~~Strikethrough~~, or Cmd/Ctrl+Shift+X
  • Code: `Code`, or Cmd/Ctrl+E
  • Link: [Link text](https://example.com), or Cmd/Ctrl+K. Web and email addresses become links by themselves.
  • Heading: ### Heading, or Cmd/Ctrl+Shift+H. One to six #: the fewer, the bigger.
  • Quote: > Quote, or Cmd/Ctrl+Shift+.
  • Paragraphs: leave a blank line between them. A single line break shows as a space; end a line with \ to break it there.
  • A mark as itself: put \ before it, as in \*. HTML tags show as written.

Lists and blocks

  • Bulleted list: - Item, or Cmd/Ctrl+Shift+8
  • Numbered list: 1. Item, or Cmd/Ctrl+Shift+7
  • Task list: - [ ] To do and - [x] Done, or Cmd/Ctrl+Shift+L
  • In a list, Enter starts the next item. Enter on an empty item ends the list.
  • Table: a header row such as | Name | Role |, then | --- | --- |, then a line for each row. The Table button starts one.
  • Code block: a line of ``` before and after the code. Name the language after the first, as in ```js, to color it.
  • Raw HTML, if the site allows it for you: a line of ::: html before the HTML and a line of ::: after it, with a blank line before. Otherwise the HTML shows as written. HTML block in the ⋯ menu starts one.
  • Horizontal rule: --- on a line of its own, with a blank line before it.
  • Footnote: Text.[^1], and [^1]: The note. on a line of its own. Notes are numbered and listed at the end.
  • Image: ![Description](https://example.com/cat.png)

In the editor

  • Buttons that don't fit in the toolbar move to the ⋯ menu. It also adds a horizontal rule, a footnote, a code block, an HTML block, a mention, or an image.
  • Mentions: type @ and a name, then pick the person with the arrow keys and Enter or Tab. Escape closes the list.
  • Images: paste or drop them, or choose them with Image… in the ⋯ menu. PNG, JPEG, GIF and WebP are accepted. A placeholder holds each one's place until it has uploaded. Photos lose details such as where they were taken.
  • Preview shows the comment as it will look.
  • Post, or Cmd/Ctrl+Enter, sends the comment once it has text and every image has uploaded.
  • The toolbar is one Tab stop: move along it with the arrow keys. The arrow keys also switch between Write and Preview.
